# Chispa v2 design

- Global navigation: Home, Lists, Search, Projects, More.
- Priority is an item attribute: Need to have / Nice to have.
- Categories classify ordinary lists; Projects are separate containers.
- Solar-specific Wiring and Suppliers exist only inside the Starlink solar project.
- Prices are stored in their original currency. MXN/USD display is derived from one exchange rate.
- Saved offers include price, shipping, tax, import fees, discount, source, URL, seller, and date; ranking uses landed cost.
- Starter solar amounts are labelled planning estimates rather than verified market prices.
- Mobile-first, neutral warm palette, simple line icons, no emoji-as-design-system, no global solar framing.
