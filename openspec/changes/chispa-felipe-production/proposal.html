OpenSpec Proposal: Chispa V2 & Felipe Interactive Project

Problem Statement

Chispa needs to transition into a calm, Apple-polished personal operations product. Additionally, the Felipe Kit de Arenero project must be integrated as an interactive, Supabase-backed project with real CRUD, link verification, budget comparison, and share token capabilities.

Proposed Solution

1. Neutral Apple-inspired UI design system (#F5F5F7, #FFFFFF, #1D1D1F, #0071E3) with ZERO emojis.
2. Information Architecture: Home, Projects (/projects/felipe-litter-kit), Shopping, Tasks, Notes, Receipts, Budgets, Inventory, Settings.
3. Supabase isolated schema migration with 15 chispa_* tables, RLS policies, and seed data.
4. Felipe screen featuring item list, detail side-sheet, budget comparison table, setup protocol, checklist, timeline, and share links.
