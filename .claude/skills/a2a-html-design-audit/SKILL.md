# A2A HTML Design Audit Skill

## Purpose
Enforces HTML-first audit reports (`audit.html`, `prd.html`, `fix-lab.html`, `implementation-report.html`) containing evidence, screenshots, scores, and clear criteria before and after UI implementation.

## Strict Rules
1. **No Emojis**: Never output emojis in UI code or audit templates. Use text and neutral SVG icons.
2. **HTML Handoff**: Audit results must be written as self-contained HTML files.
3. **Scorecard**: Evaluate on visual hierarchy, accessibility (WCAG 2.2 AA), contrast, touch targets (44px min), responsiveness, and native interaction feel.
4. **Safety**: Enforce rollback snapshots before editing code.
